# 比例截圖工具

免安裝的靜態網頁工具。可透過 Chrome 或 Edge 的螢幕分享功能，擷取螢幕、視窗或分頁，並以固定比例裁切後下載 PNG。

## 使用方式

建議在此資料夾執行 `./start.ps1`，再開啟 `http://localhost:8080`。選擇比例後按下「開始擷取螢幕」。選擇畫面後可拖曳裁切框或拉動四角調整範圍，最後下載 PNG 或複製選取範圍。

僅需下載圖片時，也可以直接以瀏覽器開啟 `index.html`。

> 「複製選取範圍」需在 `localhost` 或 HTTPS 網址下以 Chrome／Edge 開啟，這是瀏覽器對剪貼簿的安全限制。

> 瀏覽器基於安全限制，需由使用者主動選擇可擷取的螢幕或視窗；此工具不會自行讀取螢幕內容。

選取分享內容後，工具會嘗試自動回到原本視窗；是否允許切換焦點仍由瀏覽器決定。

## 支援比例

- 16:9
- 4:3
- 1:1
- 9:16
- 不限：不鎖定比例，可自由拉出任意矩形
- 自訂：輸入寬與高後套用（例如 3:2）

## 輸出與操作

- 可選擇 PNG、JPEG 或 WebP 格式下載；JPEG／WebP 可調整畫質。
- 縮放瀏覽器視窗時，裁切框會依比例保留位置。
- 使用方向鍵以 1px 微調裁切框，按住 Shift 則以 10px 移動。
