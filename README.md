# 比例截圖工具

免安裝的靜態網頁工具，可擷取螢幕、視窗或分頁，依指定比例裁切，並下載圖片或複製到剪貼簿，適合製作簡報、社群素材及介面截圖。

**線上使用：** [開啟比例截圖工具](https://demo.adevic.dev/screenshot/)

## 使用前準備

- 建議使用最新版桌面版 Chrome 或 Edge，透過 HTTPS 或 `localhost` 開啟。
- 擷取時，須由使用者在瀏覽器分享視窗中選擇畫面並允許分享；可選來源依瀏覽器及作業系統而異。
- 使用剪貼簿功能時，瀏覽器可能要求授予權限；若無法複製，可改用下載功能。

## 操作步驟

1. 開啟[線上工具](https://demo.adevic.dev/screenshot/)，選擇所需比例：`16:9`、`4:3`、`1:1`、`9:16`、**不限**或**自訂**。自訂比例請輸入寬與高，再按「套用比例」。
2. 按「開始擷取螢幕」，在瀏覽器視窗中選擇螢幕、視窗或分頁，並確認分享。工具會擷取一張畫面，隨即停止分享。
3. 在預覽畫面中拖曳裁切框移動位置，或拖曳四角調整大小。選擇「不限」可自由調整寬高；其他選項會維持所選比例。
4. 確認畫面下方的輸出尺寸。需要更換畫面時按「重新選擇畫面」；切換比例會重新設定裁切範圍。
5. 選擇輸出格式與畫質，然後按「下載圖片」或「複製選取範圍」。

### 輸出選項

| 操作 | 說明 |
| --- | --- |
| 下載 PNG | 無損圖片，無須調整畫質。 |
| 下載 JPEG / WebP | 可調整畫質，適合需要控制檔案大小的情境。 |
| 複製選取範圍 | 複製 PNG 圖片到剪貼簿，與下載格式的選擇無關。 |

下載檔名格式為 `screenshot-YYYYMMDD-HHMMSS`，副檔名依輸出格式決定。縮放瀏覽器視窗時，裁切框的位置與大小會依畫面比例調整。

### 鍵盤操作

- 使用方向鍵移動裁切框，每次移動 1 個畫面像素；按住 `Shift` 則每次移動 10 個畫面像素。
- 若焦點位於按鈕、輸入框或選單，請先點擊其他位置再使用方向鍵。

## 常見問題

**無法開始擷取？** 請使用支援螢幕擷取的 Chrome 或 Edge，透過 HTTPS 或 `localhost` 開啟，並確認瀏覽器與作業系統的螢幕錄製權限。若取消分享視窗，可再次按「開始擷取螢幕」。

**無法複製圖片？** 請確認使用 HTTPS 或 `localhost`，並檢查瀏覽器的剪貼簿權限；也可以改用「下載圖片」。

**分享後沒有自動回到工具？** 工具會嘗試切回原視窗，但實際行為由瀏覽器決定；請手動切回工具分頁。

**線上網站顯示舊內容？** 請重新整理頁面；若仍未更新，可能需要清除 Cloudways 應用程式快取。

## 本機開發

此專案是純 HTML、CSS 和 JavaScript 靜態網頁，無須安裝套件或設定環境變數。Windows 環境需先安裝 Python，然後在專案目錄執行：

```powershell
./start.ps1
```

開啟 `http://localhost:8080`。如需指定其他連接埠：

```powershell
./start.ps1 -Port 8081
```

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面結構與操作介面 |
| `styles.css` | 頁面樣式 |
| `app.js` | 擷取、裁切與輸出邏輯 |
| `start.ps1` | 啟動本機靜態伺服器 |
| `.github/workflows/deploy.yml` | GitHub Actions 部署流程 |

## 部署與維護

推送到 `main` 分支後，GitHub Actions 會將 `index.html`、`app.js` 和 `styles.css` 上傳至 Cloudways 的 `public_html/screenshot/`；也可在 GitHub Actions 手動執行 **Deploy to Cloudways**。流程結束後會檢查線上網址是否回應成功。

部署需要 GitHub Actions Secrets：`SSH_HOST`、`SSH_USER`、`SSH_PRIVATE_KEY`；`SSH_PORT` 未設定時使用 `22`。伺服器需信任對應公鑰，且帳號必須有目標目錄的寫入權限。請勿將私鑰或其他憑證提交至儲存庫。

擷取畫面在瀏覽器端處理；目前專案程式碼沒有將截圖上傳至伺服器的功能。
